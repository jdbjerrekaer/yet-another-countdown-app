## Important Notes

1. **App Store Connect Keywords:** The keywords field in App Store Connect has a 100-character limit. Use commas to separate keywords (no spaces after commas).

2. **App Name vs Display Name:** 
   - App Name (App Store Connect): `Yet Another Countdown` (30 chars max)
   - Display Name (Info.plist): `Yet Another Countdown` (what users see on home screen)

3. **Description Versions:** Three description versions are provided:
   - Full (1,104 chars) - Comprehensive feature list
   - Concise (604 chars) - Balanced detail
   - Short (337 chars) - Quick overview
   Choose based on your preference and testing results.

4. **Screenshots:** Visual assets are critical for conversion. Focus on showcasing:
   - Widget previews (unique feature)
   - Recurring events (differentiator)
   - Drag-and-drop (UX highlight)

5. **Testing:** After publishing, monitor:
   - Keyword rankings
   - Search impressions
   - Conversion rates
   - User reviews mentioning features
